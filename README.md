# 交接班系統 Handover System

目前架構為「前端 + Node.js API + SQLite 資料庫」。

## 已完成

- 早班／午班／夜班
- 原有部門與新增的水果組、蔬菜組
- 一般人員只能查看自己的部門
- 系統管理者可查看全部部門
- 每部門可有 1 名經理＋多名職員
- 人員姓名、職務名稱、員工工號（帳號）
- 新增交接時指定接班人
- 指定接班人產生持久化通知
- 右上角 🔔 未讀通知數量
- JWT 登入驗證
- bcrypt 密碼雜湊
- 使用者可自行修改密碼
- 系統管理者可新增、編輯、停用使用者
- 系統管理者可設定一般使用者／系統管理者權限
- Excel 批次匯入人員
- Excel 匯入可使用公司實際部門名稱與職務名稱，不受預設清單限制
- 新匯入帳號初始密碼統一為 `1234`
- 已存在的員工工號會略過，不覆蓋既有資料
- 新匯入部門會自動出現在交接畫面的部門清單

## Excel 匯入格式

第一個工作表必須包含以下四欄，欄名請保持一致：

| 部門名稱 | 員工工號(帳號) | 中文姓名 | 職務名稱 |
|---|---|---|---|
| 水果組 | F001 | 王小明 | 水果組職員 |
| 蔬菜組 | V001 | 陳小華 | 蔬菜組職員 |

支援 `.xlsx`、`.xls`、`.csv`。

匯入規則：

- 新帳號：建立為一般使用者、啟用狀態、初始密碼 `1234`
- 工號已存在：略過，不覆蓋原有資料
- Excel 內工號重複：後面的重複列略過
- 單次最多 500 筆
- 部門名稱與職務名稱原樣保存
- 匯入完成後會顯示新增、略過與錯誤筆數

## 本機試用

需要 Node.js 22 以上。

在 Repository 根目錄執行：

```bash
npm install
npm start
```

看到：

```text
Handover System API running on http://localhost:3000
```

再開啟：

```text
http://localhost:3000
```

管理者登入後，左側會出現「👤 人員與權限」，可以進入管理頁並使用 Excel 匯入功能。

## 資料庫

本機資料庫：

```text
handover.db
```

預設位置：

```text
C:\Users\\<使用者>\\handover-system\\handover.db
```

GitHub 只保存程式碼，不保存 `handover.db`。

## 重要：GitHub Pages

GitHub Pages 只能提供靜態前端，無法直接執行 Node.js 與 SQLite。因此正式版本不能只靠 GitHub Pages。

正式上線需要把 Node.js API 與 SQLite 放到可以執行 Node.js 的 Windows/Linux Server 或其他伺服器環境。

正式環境至少建議：

- HTTPS
- 使用環境變數設定 `JWT_SECRET`
- 資料庫定期備份
- 公司內網／VPN／防火牆控管
- 強密碼政策
- AD/LDAP 整合
- Audit Log
